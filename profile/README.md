# Coach Koala

**AI-Powered Product Management Coaching**

Coach Koala is your always-available product strategy partner. Get instant, expert guidance on prioritization, roadmapping, metrics, and more - powered by advanced AI that understands the nuances of product management.

## What We Do

- **Prioritization Frameworks** - RICE, ICE, MoSCoW and custom scoring models
- **Roadmap Strategy** - Time horizon planning, now/next/later frameworks
- **Metrics & KPIs** - North Star metrics, OKRs, and driver trees
- **Stakeholder Communication** - Exec summaries, team updates, customer narratives
- **Product Discovery** - Jobs-to-be-Done, opportunity mapping, user research synthesis
- **Go-to-Market** - Launch planning, positioning, competitive analysis

## Repositories

| Repository | Description |
|------------|-------------|
| [koala](https://github.com/Coach-Koala/koala) | Builder repo - orchestrates full-stack development |
| [koala-ui](https://github.com/Coach-Koala/koala-ui) | Next.js 14 frontend application |
| [koala-backend](https://github.com/Coach-Koala/koala-backend) | Phoenix/Elixir API with Claude integration |
| [koala-docs](https://github.com/Coach-Koala/koala-docs) | Product Bible, brand assets, and documentation |

## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend**: Phoenix/Elixir, PostgreSQL
- **AI**: Claude API with real-time streaming responses
- **Auth**: Google OAuth, Apple Sign-In, Magic Links
- **Infrastructure**: Docker, Fly.io

## Getting Started

```bash
# Clone with submodules
git clone --recurse-submodules git@github.com:Coach-Koala/koala.git
cd koala

# Initialize and start
make init
make up
```

Open http://localhost:3000 to start chatting with Coach Koala.
